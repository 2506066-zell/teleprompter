# Project Context

## Nama produk
**Focus Teleprompter**

## Problem
Teleprompter tradisional memaksa manusia mengikuti kecepatan mesin. Teks berjalan dengan kecepatan tetap sehingga pengguna harus mengejar teks, terutama saat membuat konten dengan smartphone dan layar kecil.

## Product principle
> Don't make humans follow the teleprompter. Make the teleprompter follow humans.

## Target user
- Content creator pemula hingga profesional
- Mahasiswa/presenter
- Podcaster/talking-head creator
- Pengguna smartphone yang membutuhkan script besar dan mudah dibaca

## Core experience
Pengguna memasukkan script, sistem mengubahnya menjadi unit bacaan yang mudah dicerna, lalu teleprompter dapat bergerak berdasarkan pacing, suara, dan secara opsional sinyal wajah.

## Primary use case
Smartphone dipakai untuk merekam video. Teks dibaca dari layar kecil/secondary display/teleprompter attachment yang berada dekat kamera. Karena itu keterbacaan dan stabilitas fokus lebih penting daripada dashboard kompleks.

## Core systems
1. Smart Chunking
2. Auto-Pacing
3. Voice Tracking
4. Face Tracking
5. Adaptive Decision Engine

## Product boundaries
Aplikasi bukan video recorder dan bukan cloud storage rekaman. Kamera/mikrofon digunakan sebagai input real-time dengan pendekatan privacy-first.
