# UI/UX Direction

## Design character
Premium, minimal, calm, focused, professional.

## Anti-patterns
- Generic SaaS dashboard
- Excessive cards
- Rainbow gradients without purpose
- Too many controls visible at once
- Hover-only interactions
- Tiny text
- Fake AI visuals

## Typography
Typography is the primary interface. The script is the hero.

## Focus zone
Active chunk should stay near a predictable visual center. Previous and next chunks provide context but must not compete visually.

## Mobile
Target widths: 320, 360, 390, 412, 430px.

Landscape must receive dedicated layout decisions rather than merely shrinking portrait.

## Accessibility
- High contrast
- Large tap targets
- Keyboard shortcuts where useful on desktop
- Reduced motion respect where practical
