# Features Specification

## Dashboard
Menampilkan project dan script milik user, quick create, recent items, dan akses settings tanpa menjadi generic SaaS dashboard.

## Script Editor
- Text editor
- Title
- Word count
- Character count
- Estimated reading duration
- Autosave debounce
- Chunk preview

## Teleprompter Controls
- Play/Pause
- Previous/Next
- Speed
- Font size
- Mode
- Fullscreen
- Mirror mode
- Voice enable
- Camera enable

## Focus Mode
Saat membaca, UI harus memprioritaskan teks. Kontrol dapat diminimalkan agar tidak menutupi active chunk.

## Status feedback
Tampilkan status permission dan tracking secara kecil dan jelas. Jangan gunakan indikator palsu.
